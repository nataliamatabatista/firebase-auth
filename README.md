# Firebase Auth

Aplicação React criada para cadastro e login de usuários usando Firebase.

O sistema possui uma tela de cadastro com e-mail, senha, nome, sobrenome e data de nascimento. Ao cadastrar, o usuário é criado no Firebase Authentication e seus dados são salvos no Firestore.

Também possui uma tela de login. Quando o usuário informa e-mail e senha corretos, ele é enviado para a página principal.

Na página principal são exibidos os dados do usuário logado, buscados no Firestore pelo UID. A página também possui botão para sair da conta.

Tecnologias usadas:

- React
- React Router DOM
- Firebase Authentication
- Firestore
- Vite
